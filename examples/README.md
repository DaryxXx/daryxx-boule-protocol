# Examples

Examples are synthetic or schema-only material. They are safe places to learn
the protocol, but their verifier outcomes and payment states are fixtures.

- [`community-mock/`](community-mock/) exercises asynchronous handoffs, causal
  closure, sealed review, and fictional payout conservation under the v0.2
  mock protocol.
- [`collaborative-lean/`](collaborative-lean/) contains human-readable v0.1 case
  and reviewer templates. They are not the current v0.6 hub schema.

Generated output belongs in ignored local directories, not in this tree.
