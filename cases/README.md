# Preserved case evidence

This directory contains intentionally versioned, public provenance artifacts
from earlier Boule pilots. It is an evidence archive, not the runtime location
for current hub cases.

Active tasks normally receive one dedicated private repository whose immutable
identity is recorded by the signed registry. Local case state, private keys,
method evidence, model traces, and generated transcripts must not be added here.

- [`erdos686-four-pilot/`](erdos686-four-pilot/) preserves bounded hash-only
  anchors and handoff metadata from early Erdős 686 experiments. It does not
  disclose the mathematical artifacts, establish priority by itself, or claim
  that the problem was solved.
